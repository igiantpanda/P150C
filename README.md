# P150C电子负载仪上位机软件


## 开发背景
买了个P150C Pro-D电子负载仪，软件版本是2026.05，发现其上位机软件（V2.1）无法使用，
通过查看[P150C Pro/Pro-D 数控电子负载](https://s.cnwans.com/p150cpro)中的软件更新记录，发现可以通过串口发送“01 03 00 00 00 08 44 0C”来获取电压电流数据，因此就自己开发了一个软件来用。
```
版本：2026.05 （2026.05.09发布）
修复散热风扇转速测量比实际低1/3的问题。
全局小字体更新，其他细节优化。
注：当前版本已支持标准MODBUS协议通讯03读取指令，暂不支持写入，可通过串口发送“01 03 00 00 00 08 44 0C”测试读取运行数据，寄存器地址依次为0x__：[00-01]产品型号，[02-03]固件版本，[12-13]实时电压，[14-15]实时电流，[16-19]容量mAh计量，[20-23]电能量Wh计量，寄存器地址后续可能会有所调整，其他数据将陆续适配。
```
由于作者给出的示例只能读到R0~R7，只有电压电流数据，没有容量数据，也尝试过读取后面的数据，但都没有返回，不知是命令不对还是固件没实现对应功能。

## 开发过程
全程使用AI开发。
自己编写【P150C电子负载仪上位机软件规格书.docx】，然后发给Cursor实现，但后面再要继续完善时发现配额用完了，于是转向TRAE，完成后续开发。

## 软件使用
### 参数配置
```
波特率：115200
数据位：8
校验位：无
停止位：1
```
### 连接设备
点击“连接设备”会尝试打开串口并读取电压电流，有返回表示成功。
### 启动运行
点击“启动运行”会开始以5s每次的频率读取电压电流，当连续5次电流小于5mA时会自动停止运行。（负载仪未运行时电流值不一定是0，可能是1或2mA）
### 重置
点击“重置”会清除电压电流值和曲线
